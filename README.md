# Photo Date Fix

Photo Date Fix is an Android application built with .NET MAUI that helps users detect, edit, and update the EXIF date and time metadata of photos.

## Features

- Select one or multiple photos
- Automatically detect date and time from filenames
- Manually edit photo date and time
- Update EXIF metadata
- Clean and responsive user interface

## Tech Stack

- .NET MAUI
- C#
- XAML
- MetadataExtractor

## Platform

- Android
